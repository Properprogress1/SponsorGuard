# Workforce right-to-work records

Open **Workforce** to view engaged individuals grouped by their configured engagement categories. Filter by category and check status. The CSV includes every row that matches the filters, across all pages. It contains names, references and the recorded responsibility for checks, so handle it as workforce data.

The status comes from the latest check date on file. When several checks have the same date, the record ID resolves the tie consistently. A follow-up is due on or before the current date in Europe/London. A person with no check on file appears in the missing status. The view describes records on file and the assignment recorded by the organisation.

Owners and admins can add categories and rename their labels in **Manage engagement categories**. Each organisation starts with employee, contractor, subcontractor, agency and platform. Use the stable category identifier in People CSV imports. Record a person, team or provider in the optional **Recorded responsibility for checks** field on the engaged individual’s People record. MFA-verified members can view and export their own organisation’s records.

Before rolling back the workforce migration, reassign records in custom categories to one of the five original identifiers. The rollback removes the category settings and recorded responsibility field.
